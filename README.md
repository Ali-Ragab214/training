# FitFlow — Home Workout Tracker

A mobile-first React 19 + Vite 8 single-page app for a beginner exercising at home. It implements the full specification in `IMPLEMENTATION_PLAN.md` (consolidated from `AGENTS.MD` and `Exercices.md`): two structured bodyweight workout days with exercise visuals, set/duration tracking, rest timers, a weekly calendar, workout history, weekly goals, and localStorage persistence.

## Features

- **Dashboard (`/`)** — date greeting, weekly consistency strip (Mon–Sun), Day 1 / Day 2 cards with Start/Continue, motivational message, and a personal note card.
- **Workout sessions (`/workout/day1`, `/workout/day2`)** — one shared session page for both days. Each exercise card has an SVG illustration, target muscles, sets × reps (or duration), rest interval, expandable step-by-step instructions, common mistakes, easier variation, safety/important notes, and a per-side badge for unilateral moves.
  - Per-set tap-to-complete buttons (undo by tapping again).
  - Duration-based moves (warm-up, cool-down, Knee Plank) use a "Mark Complete" pill instead.
  - A single timestamp-accurate rest timer (start/pause/resume/reset/skip), auto-opened when a set is completed.
  - Finish is enabled once every exercise is complete; progress is saved to localStorage on every change, so sessions survive refreshes and navigation. Days are fully independent.
- **Calendar (`/calendar`)** — week navigation (past weeks included), today highlighted, completed training days checked, manual mark/unmark on past and current days, per-week completed-workout count and history.
- **Progress (`/progress`)** — stats, configurable weekly goal (default 3, persisted), six-week consistency bars, and full history list with empty states.

## Commands

```bash
npm run dev       # start the dev server
npm run build     # production build (runs automatically-checked)
npm run lint      # eslint (currently clean)
npm run preview   # serve the production build
```

## Verification scripts

```bash
npm run preview -- --port 4173 &
node scripts/e2e-smoke.mjs      # 36-check Playwright smoke test (flows, persistence, dedupe, overflow at 320–1440px)
node scripts/screenshots.mjs    # takes screenshots into /tmp/opencode
node scripts/generate-exercise-svgs.mjs  # regenerates public/images/exercises/*.svg
```

`playwright` is a devDependency used only by the verification scripts (browsers: `npx playwright install chromium`).

## Structure

- `src/data/workouts.js` — canonical Day 1 + Day 2 exercise data (stable IDs).
- `src/hooks/` — `useWorkoutSession`, `useWorkoutHistory`, `useRestTimer`, `useLocalStorage`.
- `src/services/storage.js` — safe localStorage JSON read/write (malformed data never crashes the app).
- `src/components/` — layout (Layout, BottomNav), workout (ExerciseCard, SetTracker, RestTimer, WorkoutHeader, CompletionScreen, UnilateralBadge), calendar (WeeklyCalendar, WeekStrip), progress (HistoryList, WeeklyGoal), ui (ProgressBar, ExerciseImage, EmptyState).
- `public/images/exercises/*.svg` — one unique stick-figure illustration per exercise, generated by `scripts/generate-exercise-svgs.mjs`.

## Notes

- Design tokens live in `src/index.css` as Tailwind v4 `@theme` variables; solid CTA buttons use `primary-dark`/`success-dark`/`error` shades that meet WCAG AA contrast with white text.
- `prefers-reduced-motion` is respected globally in CSS and via `MotionConfig reducedMotion="user"`.
- General fitness guidance only — not medical advice.
